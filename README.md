# Omarchy Arc Theme

![Arc Theme Preview](preview.png)

Tactical 70s/80s cassette-futurism theme for [Omarchy](https://omarchy.org/) inspired by ARC Raiders:

- **Surfaces:** Weathered steel (`#2e353d` / `#252b32` / `#1e2329`)
- **Foreground:** Retro bone (`#ece7da`)
- **Accent:** VFD phosphor cyan (`#38e8d6`)
- **Background:** Matching 5K wallpaper (`backgrounds/0-launch.webp`) and animated intro (`backgrounds/intros/0-launch.mp4`)

## Installation

```bash
omarchy theme install https://github.com/rougerio/omarchy-arc-theme
```

## Activation

```bash
omarchy theme set Arc
```
